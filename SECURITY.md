# Security policy

Please do not post Microsoft tokens, proxy credentials, private access links, signing keys, or server secrets in a public issue.

For a security vulnerability, use GitHub's private vulnerability reporting feature for this repository. Include reproduction steps, affected versions, and the expected impact. Do not test against accounts or servers you do not own or have permission to access.

AFK Desk never needs a Microsoft password. Authentication uses Microsoft's device-code flow, and credentials should remain in application-private storage.
