## Component recursion: needs protocol-boundary verification

`electron/bot-manager.cjs:1201-1211,1278-1314,1796-1815` recursively walks server-controlled components without depth/node budgets. A 12,000-level empty `extra` chain passed directly to the exported chat helper throws `RangeError: Maximum call stack size exceeded` on host Node. The segment cap does not bound empty-child traversal. This demonstrates a helper failure, not a network exploit: upstream packet/JSON parsing limits and actual event delivery must be established before claiming a remotely induced process crash. Use bounded iterative parsing with a safe event-boundary fallback.

## Scope and claims review

Reviewed main-window/preload/IPC controls, store behavior, Java/Bedrock session and retry paths, event persistence, resource-pack fetch/cache/parser boundaries, proxy connection handling, profile paths, version/protocol adapters, and renderer text/action surfaces. This was a focused trust-boundary review, not an exhaustive line-by-line proof of every helper or asset. Native libraries and every patched upstream protocol path are not dynamically certified.

`docs/AUDIT.md` is a historical September baseline: the empty-account, display-name and command-serialization findings were subsequently addressed; its release-position paragraph is not a current release inventory. `docs/HARDENING-STATUS.md` correctly leaves resource destinations, token caches, native/live behavior and universal mod compatibility open. Its test counts and zero-advisory snapshot are historical; use [current verification](2026-10-14-verification.md) and [hygiene audit](2026-10-14-hygiene.md).

Microsoft auth flows still use Prismarine Auth's file cache. Installed `prismarine-auth/src/common/cache/FileCache.js:10,32` writes JSON without an encryption wrapper or explicit mode; `src/MicrosoftAuthFlow.js:52,64` creates the directory and selects that cache. OS/inherited ACLs remain relevant. Proxy safeStorage does not encrypt these token caches. No existing profile, token file or installed app data was inspected. Desktop deletion explicitly warns that tokens remain (`src/renderer.js:949`); retention is not presented as an undocumented deletion bug.

The actual isolated Electron smoke passed with an empty temporary user-data directory and 28 versions. All 222 desktop tests and the Edge browser fixture smoke passed. Those results do not prove authenticated servers, native Bedrock sessions, long-running reconnect health, or installer qualification.
