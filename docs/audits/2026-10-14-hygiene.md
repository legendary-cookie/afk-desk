## Advisory details and interpretation

Desktop production findings are `axios` 1.19.0 (high), a production `glob` copy of `brace-expansion` 1.1.18 (high), and `ip-address` 10.3.1 (moderate). The embedded engine's affected package is `ip-address` 10.3.1. Scoped `uuid` 11.1.1 overrides still exist in both engines; that older UUID remediation does not cover later advisories elsewhere.

Primary advisory records returned by npm include [Axios redirect SSRF](https://github.com/advisories/GHSA-r4gj-5m52-g5wh), [brace-expansion recursion](https://github.com/advisories/GHSA-qhr7-859c-m2p7), and [ip-address family comparison](https://github.com/advisories/GHSA-j6r3-76f7-8jcv). The application's global-fetch resource-pack flaw is independent of the Axios advisory; this audit did not prove these advisories reachable through server packets.

Top-level mobile reports critical `shell-quote` 1.10.0 ([advisory](https://github.com/advisories/GHSA-pqg4-j6r4-53mv)), plus high dependency chains through RN/Metro/Jest-related packages and moderate UUID/nodejs-mobile/xcode chains. This is a package-graph observation, not a demonstrated remote command execution path in AFK Desk. `--omit=dev` excludes root dev-only dependencies but does not exclude framework/tooling pulled transitively by production dependencies. Track build-host and shipped-runtime reachability separately. Some npm suggested fixes are React Native major upgrades; the bridge reports no automatic fix for some chains. Broad upgrades require native compatibility qualification.

`npm outdated --json` exits 1 in all three roots, which means newer versions are offered, not that every old version is vulnerable. Examples: RN 0.76.7 versus registry latest 0.87.1, ESLint 8.57.1 versus 10.12.0, TypeScript 5.0.4 versus 7.0.2. The runtime support mismatch and advisory evidence determine priority; age alone does not.

## CI and supply-chain hardening notes

- CI grants `contents: read`, uses ordinary `pull_request`, and contains no direct event-text interpolation into shell. Actions use mutable `@v4` tags (`ci.yml:18-19,35-36`); pin full reviewed SHAs to narrow supply-chain trust. This is defense in depth, not a demonstrated pipeline compromise.
- Cache keys use the job's primary lockfile; the separately installed embedded-engine lock is absent from cache-dependency-path. This affects cache completeness/performance, while `npm ci` still verifies its own lock. No release job consumes PR-created build artifacts here; no cross-trust cache attack was confirmed.
- Only `ci.yml` is tracked under `.github`. Dependabot and CodeQL/secret-scanning workflow configuration are absent. GitHub server-side security feature settings were not queried, so their enablement is unknown.
- `minecraft-protocol-forge` is a Git dependency, not an unpinned tarball. The manifest uses shortened commit `54fc6a2f`; the lock resolves full commit `54fc6a2f72303bfd9042142546b2adb65739de03`. Current installation succeeded. Prefer the full manifest commit and document provenance; commit pinning is already present in the lock.
- tar/axios overrides, scoped engine UUID overrides, and mobile brace-expansion/minimatch overrides are explicit. Some exact overrides are now affected by newer advisories; existence of an override does not imply current security.

## Versions, tests and policy fidelity

Desktop and embedded `supportedVersions()` both return exactly the same 28 values, 1.8.8 through 1.21.11. The RN picker matches that list. The matrices are meaningful local protocol client/server tests, not only object mocks: `desktop/test-fixtures/functional-version-matrix-runner.cjs:85,107` creates a loopback offline-mode server and Mineflayer client. World/physics fixtures are synthetic; authentication is offline. Mobile-engine matrices run under the host Node executable, not inside Android Node. This does not certify arbitrary servers/modpacks, Microsoft auth, native Bedrock, public network routing or actual Android compatibility. README/CHANGELOG descriptions of local coverage should retain those boundaries.

Coverage is strongest for unit/lifecycle/resource/store/IPC helpers and local Java protocol matrices. Preload/UI-contract tests include source-pattern assertions; browser smoke stubs the bridge. `main-security.test.cjs` mocks Electron. RN tests mock Keychain/native bridge/service boundaries. No direct malformed-command suite for embedded `main.js`, real Bedrock native lifecycle suite, Android instrumentation suite, or iOS build/runtime gate was found. This is a test inventory, not an instrumented line-coverage measurement; do not call every uninstrumented module untested. Protocol fixes are exercised indirectly through bot/matrix tests.
